Chapter demos

Experimental mini apps that illustrate manuscript ideas. They are not part of the PDF and are not validation of frontier systems — sanity-check toys for intuition.

Try a demoSource on GitHub

How to run

Integrated (recommended): ./serve-site.sh — serves the site and copies demos into /chapter-demos/. Backend demos (UAD board, scaffold-misuse LLM API) proxy to local Python automatically when dependencies and keys are present.

Demos only: ./serve-demos.sh or cd demos && python3 serve.py — static demos at port 8765; Python backend demos on their own port.
