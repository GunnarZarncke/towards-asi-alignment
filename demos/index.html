How to run

Integrated (recommended): ./serve-site.sh — serves the site and copies demos into /chapter-demos/. The UAD board proxies to a local Python backend automatically.

Demos only: ./serve-demos.sh or cd src && python3 serve.py — static demos at port 8765; Python backend demos on their own port.
