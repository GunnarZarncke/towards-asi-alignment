# Drafts

Working notes, lane plans, and agent handoff — not manuscript canon. Git history is the diff record; [`conversation-summaries/`](conversation-summaries/) is the session handoff record.

## Start here

| Need | Go to |
|------|--------|
| Resume agent work | [`conversation-summaries/HANDOFF.md`](conversation-summaries/HANDOFF.md) → [`metadata/TODO.md`](../metadata/TODO.md) |
| Lane checklists | [`plans/README.md`](plans/README.md) |
| Closed / superseded plans | [`attic/`](attic/) |
