# Repo cleanup, simplification, and archival plan

**Trigger:** review the project and act on the erasure/archival guidance in `AGENTS.md`
(§ Erasure, Archival, and Cleanup).

Findings were produced by a two-part audit (drafts/review; docs/context/metadata) with the
load-bearing claims re-verified directly. Git history is healthy — 53 MiB packed, 2,097 tracked
files, and none of the six generated `.tex` fragments are tracked. The problems are
informational: pointers that land on the wrong file, and completed work that still reads as active.

## Success criteria

- `INDEX.md` rows and log files on disk agree exactly (0 dangling, 0 unindexed).
- No generated file is rebuilt on every `./build.sh` without reaching a reader.
- Countable facts (appendix count, experiment-line count, appendix letters) agree across all docs
  and match `book.tex`.
- Completed plans live under an `attic/` with a README saying why they were retired.
- `make check` and `./build.sh` still pass at the end.

## Task 1 — Repair `drafts/conversation-summaries/INDEX.md`

**Defect.** 440 log files on disk, 429 index rows: 42 logs unindexed, 31 rows naming files that do
not exist. `AGENTS.md` tells every agent to read this index first to resume, so this misdirects
every session.

**Cause (confirmed).** Commit `bd8f82f1` "Renumber chapters and appendices" rewrote chapter numbers
*inside* `INDEX.md`, including the filename cells, without renaming the files. Example: index says
`2026-06-19-ch46-compression-test-intention-draft.md`, file is
`2026-06-19-ch21-compression-test-intention-draft.md`. Five distinct rows collapsed onto the same
fake `ch46` name.

- [x] Match the 31 dangling rows to real files by date + slug (the slug survived; only the chapter
      number was corrupted). Rewrite link targets and the visible chapter numbers in the row text.
- [x] Add rows for the 42 unindexed logs, in date order.
- [x] One dangling row is unrelated: `2026-07-19-ciris-accord-reply-eric-moore.md` was indexed but
      never written; the untracked reply itself exists as `drafts/ciris-accord-reply-eric-moore.md`.
      Point the row at the artifact or drop it.
- [x] Verify: log filenames on disk and index link targets are set-equal.
