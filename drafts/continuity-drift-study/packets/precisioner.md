# Packet: Precisioner (one case)

## Cover

You are assisting a comparative study of continuity and drift in long-lived organizations.

## Assignment

You receive **one** case name. You do not compare it with other cases. You do not rate the organization. You do not collect "how well it stayed on course" as a score.

## Bounding rules

1. **Unit.** Name the bound unit (legal person, order, church body, firm, state office, disciplinary community, etc.). If the name covers several successor bodies, pick the unit for which earliest-period primary sources and a continuous record exist; state the choice with dates.

2. **Window.** Give a start date and an end date (or "still extant" with last-document date). Each bound must have a **dated reason** (founding instrument; schism; charter rewrite; dissolution; end of available record). Do not stretch the window to make a narrative nicer.

3. **Source set.** List primary and secondary sources you will rely on. Note obvious biases (hagiography, hostile chronicle, in-house annual report, later apologetics). Prefer earliest primary sources for aims.

4. **Frozen founding aims.** From **earliest-period primary sources only**, quote or closely paraphrase the organization's own stated aims. Record citation and date. Do not update these aims using later practice, later theology, later marketing, or survival. If earliest sources disagree, record the disagreement; do not reconcile it into a single slogan.

## Output

- unit
- window (start, end, dated reasons)
- source set (primary / secondary, bias notes)
- frozen founding aims (verbatim or close paraphrase, citations)
- descriptive facts only: founding period + earliest source; duration; scale over time if easily cited; degree of codification (describe, no 1–5 scale)

Do not invent rating scales. Do not list "features of good governance."
