# Three tests on the 2021–2026 ontologies

Parent reviews: this folder. Citation policy from the user: **cite few; do not inflate the spine; do not try to cover every ontology.**

For each source, three questions:

1. **Crack.** Does this name a place misalignment can enter, or an agent-like effect TSA’s current cuts would not look for?
2. **Better fit.** Is this a better object for something TSA already has (including project-native terms such as value-bundles), or a homograph that would make the existing term worse?
3. **Kind.** Genuine **gen**eralization (TSA’s object is a special case, or vice versa, with extra structure), **special-case** of a TSA cut, **sibling**, **alt-cut** (same phenomena, neither contains the other), **method**, or **orthogonal**.

Do not add terms to the manuscript from a “yes” on (1). A crack can be real and still only deserve a reverse-crosswalk sentence or an example, not a new primitive.

**Do not recast value-bundles** as shards, representational geometry, process networks, or natural latents. Those are siblings or different types (mechanics, population-state geometry, within-person causal graph, coordination latent). Bundles stay: low-dimensional *control directions* measured across situations, plus bearer maps and transport.

**Ignore-rated physics still has a crack-lesson**, not a TSA object: a net-zero safety metric can hide a symmetry-distinct phase (altermagnetism); an “invariant” may have no inverse (non-invertible symmetry). That is already the ontology-trap / Goodhart method. Do not import condensed-matter primitives.

## Value-bundles in particular

Asked explicitly. None of these is a better *replacement* for value-bundles (low-dimensional control directions + bearers + transport):

| Candidate | Verdict |
|---|---|
| Shards | Sibling mechanics. Bundles do not commit to RL-chiseling or contextual activation. |
| Natural latents | Coordination/abstraction object. May make bundle *transport* more plausible if a value-relevant latent exists; silent on bearers and CCI. |
| Representational geometry | Homograph. Population-state geometry ≠ policy-response-to-salience geometry. |
| Process networks (PBT) | Alt-cut of the *clinical* object. Useful as a warning that bundle coordinates estimated from group data may not be the within-bearer process. Recast measurement, not the primitive. |
| Hierarchical / TAME Selves | About *who is an agent*, not about value geometry. |
| Judgements / believing-in | Epistemic types, not value types. |

## Ignore-rated items as cracks

The ignore/orthogonal rows are not “no crack in nature.” They are “no new TSA object.” The ones that still earn a *lesson* (already implied by ontology trap / Goodhart / Claim 1):

- **Altermagnetism:** a zero of the obvious order parameter is compatible with a distinct active phase.
- **Non-invertible symmetry:** some transformations you treat as “conserved” have no inverse, so restoration is not defined.
- **Transcriptomic taxonomy / analytic stacks:** the wrong grain of type or space looks complete.
- **Enemy/malefactor, gradual disempowerment, relational safety:** cracks TSA already named; extra terms would inflate.

Assembly theory and BCIO are the two ignore-adjacent cases with a *homograph hazard* (history-identity vs memory lineage; intervention catalogs vs correction). Warning, not adoption.
