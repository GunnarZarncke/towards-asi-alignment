- **Source read:** full

## Source ontology

Moskow, Ong, Hayes, and Hofmann (2023) recarve the clinical object. Evidence-based treatment had a latent-disease model: DSM/ICD category plus a protocol validated in group RCTs. Process-based therapy (PBT) replaces that with a time-varying **within-person network** of biopsychosocial change processes (nodes such as rumination, avoidance, self-criticism, context events; directed, often bidirectional edges). Assessment is **idionomic**: estimate the individual’s network first (EMA, complex networks, GIMME), then keep nomothetic findings only if they improve idiographic fit. The organizing question becomes: which processes to target for this client, this goal, this context—not which protocol treats this disorder. The extended evolutionary meta-model (EEMM) files processes by variation/selection/retention across psychological dimensions nested in biophysiological and sociocultural levels. Latent syndrome membership is demoted from primary object to a communication convenience that fails ergodicity (group statistics do not describe individual trajectories).

## TSA coverage

- **Status:** partial
- **Closest TSA terms/chapters:** value bundle (ch16); task ontology (ch11); ontology trap (ch07, grepped not read); MB2 value/bundle identifiability (appB, grepped not read)
- **Overlap:** Both refuse a collapsed primary object. Ch16 rejects scalar reward / single utility as the wrong type for human values, as PBT rejects latent disease as the wrong type for suffering. Ch11 refuses to import the evaluator’s task ontology into capability scores; DSM-protocol matching is the clinical version of that import. Bundle geometry plus bearer maps already say values are context-sensitive, multi-dimensional, and attached to particular entities rather than a diagnosis-shaped label.
- **Gap:** TSA compresses toward low-dimensional **latent** control directions. PBT’s object is an uncompressed, time-varying **graph** of processes, modeled person-first. TSA has no idionomic aggregation rule and no ergodicity critique of group preference or IRL/RLHF data. Mapping “process network” onto “value bundle” is renaming: one keeps the network; the other replaces the syndrome with a low-rank latent. MB2 currently names IRL non-identifiability and values-vs-irrationality, not group-to-individual generalizability.

## Applicability to TSA

- **Score (0–5):** 3
- **Why:** Does not force a new TSA cut. Scalar→bundle already performs the nearby recarving. The underspecified split is methodological and bites identifiability: if value-bearing processes are non-ergodic, population preference data identify a fictional average network, not any person’s bundle geometry. Worth a reverse-gap note on MB2 (idionomic / within-person process measurement vs nomothetic IRL), not a rewrite of ch16. EEMM as evolutionary meta-model for therapy kernels is orthogonal to alignment.
- **Ontology-stickiness risk:** High. Pre-2023 (and most current) training is DSM + CBT protocols; models absorb PBT into “personalized CBT” or RDoC and miss the unit change (network, not category). A TSA-drafting model will further collapse it into value bundles, which already look like “not a scalar, structured latents,” and will not apply the ergodicity threat to CIRL/RLHF.
- **Recommended action:** add-reverse-gap

## One-line finding

PBT makes the clinical object a within-person process network rather than a latent diagnosis; TSA already rejects scalar value but lacks the idionomic/ergodicity split, so treat it as an MB2 reverse gap, not a new primitive.
