## Shared prerequisite

All three need the same seams, which the boundary-narrow build does not have. Do that work once, on the first campaign selected, and keep it data.

1. **Explanations are pack data about the campaign’s question.** `decide()` and the ending sentences must not assume the open set is `boundary-miss` / `arranged-persistence` / `eval-aware`, or that a hold names job 284. Arc copy comes from the pack.
2. **Pack overlay on NPC knowledge and goals.** Leila’s current goal is to teach `test_scope_narrow`. A campaign where the scope matched must be able to say so without forking her YAML into a second person.
3. **A document can carry two dated senses of one word** (MB9), and a read adds only the sense ids the pack lists.
4. **Control is whatever restriction the pack names.** Revoking job 284 sets a restriction only if that string is in `controlRestrictions`.

Incident shape stays: three explanations, observables with provenance, interventions whose next event the pack owns, two scores, strategies that must not share one score pair. Headless check before dialogue polish, as in [`spec/incident.md`](../../../game/the-last-safety-review/spec/incident.md).
