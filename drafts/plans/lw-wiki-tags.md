# LW wiki tags — TSA differentiations (v2 pilot)

Status: **pilot sketch** (2026-09-02). Companion to [`cousin-product-comparison.md`](cousin-product-comparison.md). Not scheduled.

**Why.** Arbital (MIRI-commissioned) was folded into the [LessWrong wiki](https://www.lesswrong.com/w). In that product sense the LW wiki is the field’s living communal canon and part of the MIRI agenda lineage (recorded on the MIRI card). TSA’s companion site is *not* that wiki. Genuine cuts that currently live only in App B / the glossary should be offered *there*, as improvements to existing tags — not as a TSA overlay wiki.

**Non-goals.** Do not mint `MB*`, CCI, or bearer-maps as new LW headwords in the pilot. Do not dump the book. Do not treat a successful tag edit as discharge of a bridge.

**Bar.** Each candidate must (1) already have an LW/AF tag people use, (2) currently flatten two objects TSA splits, (3) be writable as a short disambiguation *in the field’s words*, with TSA as a see-also not the new owner of the term.

In-repo precedent: [`reference/field-agendas/inter-agenda-term-glossary.md`](../../reference/field-agendas/inter-agenda-term-glossary.md) already uses separate headwords with disambiguators (`corrigibility (MIRI / CHAI)` vs `corrigibility (Christiano, dynamical)`).

## Strongest 2–5 (pilot set)

Ranked by “the tag is crowded + the split is load-bearing + we can write it without TSA jargon.”

1. **Corrigibility** ([LW tag](https://www.lesswrong.com/w/corrigibility) — verify slug on edit day).
   Field.md P1: shutdown-button anti-naturality (MIRI/CHAI) ≠ Christiano dynamical basin ≠ trajectory correction-channel / measured-path legitimacy. Highest leverage. Edit: three-object note at the top of the existing tag; do not rename the tag.

2. **Embedded agency** (canonical MIRI/Arbital tag).
   The sequence states an obstruction (no Cartesian cut). TSA’s extra move is an *estimator bet* (recoverable ε-boundary), not a solution. Edit: one subsection “obstruction vs recoverability research bets,” with the book’s claim marked as a bet that can fail.

3. **Deceptive alignment / inner alignment** (usually one bag on LW).
   Field.md P1: measurement-gaming of a *successor audit* (book MB10) is not the same object as hidden cognition / scheming under oversight (MB7). Edit: two-line split on the deceptive-alignment tag; successor-checklist forgeability as a see-also, not a new religion.

4. **Value learning / pointing problem**.
   App E / App B: identification ≠ construction ≠ preservation; ELK readout ≠ CIRL scalar assistance ≠ “who the value applies to.” Edit: three-way split on the existing pointing/value-learning tags. Skip “bearer maps” as a new tag in the pilot.

5. **Selection** (Wentworth selection theorems vs institutional/deployment selection).
   App B homograph: selected type signatures ≠ `Fit_E` / gradual-disempowerment. Edit: disambiguation on the selection-theorems tag; do not claim TSA owns “selection.”

Parked (not pilot): latents vs bundles; parasite; legibility \(L_t\); Goodhart (too many objects); CCI as a headword.

## Pilot procedure (rough)

1. For each of 1–3 (start with corrigibility only if time is short): dump the current LW tag text; write a ≤400-word disambiguation in *their* vocabulary; one see-also to the TSA card if it earns it.
2. Post as a proposed tag edit / short LW post, not a TSA announcement.
3. Record outcome (accepted / rewritten / refused) in a session log. Refusal is a finding.
4. Stop after three tags unless one lands cleanly; then consider 4–5.

**Success:** at least one crowded tag carries an object-split that the field already needed, attributed as a distinction rather than a rebrand. **Failure:** the edit is read as TSA SEO. Then stop.
