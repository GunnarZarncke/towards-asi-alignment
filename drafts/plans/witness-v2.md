## Track A — institutional correction channels

**Question (operational):** On a **named institution** whose traces already exist, does a **named correction handle** (ombuds finding, parliamentary question, audit objection, FOI/open-data obligation, court remand, ethics board, regulator order) change a later **world or policy act**, or does the checked symbol stay green while the referent continues?

That is C-005 / MB4 (and adjacent MB4a, MB8, Expectation 4) on hosts that are not Linux, Wikipedia, or CIRIS, and not three hand-picked Appendix M trees.

**Why “transparent” polities (e.g. Denmark) are candidates, not scores.** High FOI / open-government rankings are a **data-availability** filter. They are **not** a CCI score. Using “Denmark is well-governed” as the measurand repeats W-7 (wrong unit: place). The unit is a **decision process** with a handle and a later act (bill, permit, appointment, procurement, publication).

**Candidate data classes (inventory only until freeze — do not score):**

- Parliamentary questions, committee reports, and voting records with stable IDs (e.g. Folketing / other open legislatures).
- Ombudsman or equivalent case registers with disposition + later agency reply.
- National audit offices: objection vs later budget/act.
- FOI logs where request, refusal, and later disclosure are joinable.
- Municipal or agency open-data portals with versioned publications (handle = statute or publication duty).
- Other democracies with comparable joinable tables (not a Denmark-only program).

**Refuse if:** only country indices (WGI, CPI, “open government score”); only news narrative; unit is nation-year; adolescent/restricted microdata; cannot name the handle **before** seeing uptake.

**Relation to H5:** W-9–W-11 coded **one episode each** as a Chapter 42 tree. Track A asks whether a **repeatable join** (handle → later act) exists at all. If the join cannot be built, **refuse** (valid). If it can, freeze a protocol and allow fail/null.

## Blinding — do not code for the test

v1 Witness froze protocols in the same authoring pass as checkers. That is acceptable for scripted hosts; it is **not** acceptable for Track A, where it is too easy to pick institutions and leaves that already look like CCI.

v2 uses **at least two blinded steps**, adapted from [`docs/METHODOLOGY.md`](../../docs/METHODOLOGY.md) § Blind generation (lessons 1–4, 8). Binding prompts live in a later `experiments/witness/` protocol file, not here.

### Step 0 — inventory (implementer, unblinded to data existence)

List public dumps, licenses, unit keys, and join feasibility. **No scoring criteria, no margins, no “good institution” labels.** Output: data sheet. If no joinable handle+act table exists, **stop** (refuse Track A).

### Step 1 — criteria generation (blinded)

A generator that **must not** see: the inventory’s country names, which files scored well in a pilot, Appendix M episode list, FINDINGS, or checker code.

**Permitted:** operational description of a correction channel (handle, uptake, later world act, capture / both-ends-of-channel). CCI coordinates that are **observable in principle** (ch26): valid referent, uptake, latency — not scalar \(\mathrm{CCI}_\lambda\).

**Forbidden:** “use Denmark,” “use Folketing column X,” thresholds, which leaf will fail.

**Output:** a criteria memo (what would count as handle, uptake, theater, refuse). Implementer may reject only for **incoherence / incomputability**, not for predicted difficulty (same rule as graded-lab Phase 0).

### Step 2 — evaluation protocol freeze (implementer)

Map Step 1 criteria onto **held-out** traces from Step 0. Freeze: unit, inclusion, split (institution or time), margins, outcome table. Commit this file **before** the scored collector run (M2).

If mapping requires disclosing a **rubric-derived** hint to a second generator, that is a leak (Lesson 2) — refuse or restart Step 1 with a world-fact brief fix only (Lesson 3).

### Step 3 — scoring (frozen checker)

Run once. Null/refuse/fail as registered. No retune (M5).

### Optional Step 1b

A **second** blinded generator designs the **eval split and margins** from the criteria memo plus a **schema-only** description of tables (column names, not values). Still must not see FINDINGS or which rows would pass.

**Physical isolation** if the generator is an agent with repo access: stash FINDINGS, this plan’s predicted outcomes, and Appendix M case cards (Lesson 8). Instruction-only “don’t read” is insufficient.

## v2 success / failure (program-level)

**v2 succeeds as a program if** it produces at least one of:

1. A frozen Track A protocol + finding (fail, refuse, or null) on a joinable institutional handle→act table.
2. An explicit **closure** that no public join meets Step 0 (Track A unpaid; do not keep hunting country indices).
3. At least one frozen unpaid-MB hunt (table above) that is fail, refuse, or skip-with-reason — not a new anecdote on MB1/MB2/MB4 that v1 already paid.

**v2 fails as a program (M1/M7) if** it only accumulates W-numbers on SCOTUS-like C-004 geometry, more H5 trees, or Denmark-as-score.

**Still unpaid even if Track A hits:** adversarial \(M\) at \(\kappa^*\); M8 reproduction of v1 fixtures; MB11 with AI deployment leverage.
