FAQ

Questions first

Start with a question. Each answer links to the card or path that goes deeper.

What is this site?

A static companion site for the book. It helps readers find the core ideas, choose a fixed path, and reach the PDF.

Is this a new knowledge platform?

No. It is an authored reference layer for one framework. Discussion and contributions can happen elsewhere.

What is the central thesis?

Alignment means preserving human-correctable value-bearing processes across capability growth, ontology shift, successor creation, and selection pressure.

What is correction-channel integrity?

It is the condition that legitimate human correction still causally changes future system behavior before irreversible damage.

What is a value bundle?

A compressed direction of control that changes behavior across contexts. The framework cares whether this structure survives transformation.

Why start with boundary discovery?

Because the deployed actor may be a loop of model, memory, tools, dashboards, and people. Auditing only the model can miss the real controller.

Does Lean prove alignment?

No. Lean checks conditional structure. It does not prove that real systems satisfy the bridge assumptions.

Do the experiments validate the thesis?

No. They are methodology-building and sanity checks. Negative results bound what the manuscript may claim.

Where should safety engineers start?

Use the engineer/evals path, then read the correction-channel integrity and deployment-gate cards.

Where should policy readers start?

Use the funder/policy path. It emphasizes decision triggers, scope assumptions, artifacts, and uncertainty.

Where is the full book?

The PDF is hosted on this site (PDF in the nav) and opens directly in the browser. GitHub Releases remains an alternate download channel.

Will there be translations?

Later, after the English card structure stabilizes.
