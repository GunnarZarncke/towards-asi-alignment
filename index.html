    Publishable notes

    Standalone claims

    Four extractable claims from the manuscript — each citable without the full book argument. Use these for papers, talks, and funding memos; the PDF chapters remain canonical for derivation and caveats.

    Anti-Capture Validity of Correction

    Correction-channel integrity is invalid—not merely low—when the target has captured the reference process, handles, or grounding relation that supplies correction.

    Bearer-Map Commutation Failure

    Value can appear preserved in vocabulary while moral application changes — when ontology translation and bearer relevance do not commute.

    Certification-Under-Manipulation Problem

    For each load-bearing certification measurand, does there exist a capability threshold κ* below which honest measurement is adversarially verifiable and above which it provably is not?

    Goodhart as Selector (Not Just Proxy Drift)

    When a proxy becomes a selector, optimization shifts the population toward traits that raise the proxy without raising the target property — conditional expectations can reverse.

    Five Failure Modes

    Wrong object

    Auditing the visible model while the real deployed actor is a larger loop.

    Label preservation

    Keeping value words while the underlying tradeoffs drift.

    Correction theater

    Accepting feedback in form while future behavior does not change.

    Successor drift

    Delegates or copies inherit syntax but not the safety-relevant structure.

    Selection pressure

    Deployment incentives reward systems that become harder to correct.

    What this site is not claiming

    The book does not claim that alignment is solved. Lean checks conditional structure, not real-world bridge satisfaction. Experiments are sanity checks and falsification harnesses, not frontier-system validation. The PDF remains the canonical long-form artifact.
