Philosopher Path

Why value learning is not hopeless-in-principle, where bearer and correction questions bite, and why alignment is partly an institutional selection problem.

What this path is for

You want to know whether the book earns its metaphysics and its pessimism/optimism balance—not whether a particular audit API is implementable.

You will leave knowing:

  • Why the book rejects fixed utility functions and one-shot training as the alignment object.
  • How value-bundle geometry responds to the worry that human values are too arbitrary to learn.
  • Where bearer maps and ontology shift break naive value identification.
  • Why correction is about preserving a human value-update process, not freezing current endorsements.
  • Why Claim 6 (basin / selection) makes alignment partly institutional—and why that is a feature, not a dodge.

Time: roughly 3–5 hours of cards + selected PDF chapters (Part I, selections from Parts IV–V, Part X closing).

Read in this order

  1. objectionopen

    What the Book Is Not Claiming

    The manuscript offers a framework and conditional proof spine, not a proof that superintelligence alignment is solved.

  2. conceptframework

    Value Change vs. Value Corruption

    Not all value change is a threat. The distinction between legitimate value change and corruption is load-bearing for everything the book calls correction.

  3. conceptframework

    Value-Bundle Transport

    Values should survive transformation as usable directions of control, not merely as preserved labels or slogans.

  4. conceptframework

    Bearer Persistence

    Values must keep applying to the right persons, beings, states, or processes as systems and ontologies change.

  5. conceptframework

    Correction-Channel Integrity

    Human correction must still causally change a system's future behavior before irreversible damage.

  6. conceptframework

    Socio-Technical Attractor Control

    Deployment environments can select for or destroy alignment properties even when a system starts in a better state.

  7. conceptopen

    Evidence and Uncertainty

    Every claim in the framework carries an explicit confidence label and a stated way to challenge it, rather than uniform certainty.
