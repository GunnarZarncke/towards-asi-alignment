## Problem

Multi-agent alignment research needs more than isolated technical grants. Contributors need demonstrations, project scoping, mentorship, and collaboration pathways — and the hub itself should dogfood the methods it teaches.

This is **not** the shared alignment observability platform (trace ingestion and plugin analyses). It is a **capacity** grant: practice, roster, seminars, and reflexive probes on hub operations.

## Approach

Recurring working group + project market anchored in **Hamburg and Berlin AI safety groups** and **EA Hamburg** — shared-methods seminars, mentor pairing, onboarding, and matching contributors to work packages on **separately funded** technical projects.

**Reflexive practice (hub as its own testbed):**

| Practice | What it means on the hub | Funder-facing output |
|----------|--------------------------|----------------------|
| **Agent UAD** | Run discovery-failure / collective-blind-spot probes on hub agents (pairing bot, seminar scribe, project-market workflow) | Demo series + annotated traces showing what broke |
| **Self-governance** | Documented policies for hub AI tools, data retention, human override, mentor boundaries | Governance one-pager + change log |
| **Negative results** | Hub-run experiments and seminar trials preregistered; nulls published in hub ledger | Public null export |
| **Cross-replication** | Micro-grants for replicating another participant's capstone or demo config | Replication notes per cycle; bounty ledger |
| **Correction channel** | Inspect hub's own feedback/correction paths with CCI-adjacent probes | Correction-channel audit template funders can reuse |

**Boundary:** Reflexive work produces **practice artifacts and lightweight probes** — not graded-lab rigs, not a substitute for the technical grant's evaluation spine, not productized Alignment Attractor.

**Non-goals:** Building graded-lab v2; shipping rigs; substitute for Combo 1 research grant; vague networking with no artifacts; governance theater without published probes or nulls.

The attractor is not only a venue for other people's research — it **dogfoods** multi-agent safety methods on hub operations. Lightweight UAD demos, governance norms, and ledger discipline can run on hub tooling from month 0; it does **not** require the multi-principal testbed to start.

## Milestones

- **H1 — Launch (0–3 mo):** Charter, roster, seminars, hub AI-tool governance.
- **H2 — Practice (3–9 mo):** Pairings, first reflexive UAD or correction-channel probe, hub null ledger.
- **H3 — Project market + replication (6–12 mo):** Cross-replication bounties; match contributors to funded work packages.
- **H4 — Sustain & publish (12–18 mo):** Archive, funder-usable hub-introspection pack.

Optional single-year pilot **€60k–90k / 12 months** (core ops only; reflexive layer and micro-grants deferred).

## If it works

Contributor-ready roster; external voices feeding technical grants; **hub-introspection artifacts** (correction-channel report, agent probe log) usable outside aintelope — a practice hub where multi-agent safety methods are demonstrated, taught, and applied to the hub itself.
