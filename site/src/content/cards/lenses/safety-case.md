**Role.** Protocol. Graph node `safecase`.

> Safety cases organize deployment claims, argument structure, evidence, and residual risk. … It does not prove that a real system satisfies the predicates, that the world model is complete, or that ASI alignment has been achieved.
>
> — Frames draft §4.9

The warrant-bundle path is `proof | control | cci_cert | correction → safecase`. A missing export is a missing slot, not a missing alignment frame. Lean checks conditional composition when bridges hold; it does not discharge `Safe` for a real system.
